How Intelligent Error Recovery Works

Unlike conventional compilers that immediately abort execution upon the first syntax error, the Resilient Compiler evaluates candidate recovery strategies using a 1-token lookahead scoring matrix:

  • Insertion (Cost 1-2): Injects expected synthetic tokens (e.g. missing ) before { or default literal 0 after =) when the subsequent token validates the production rule.
  • Deletion (Cost 1-2): Discards extraneous tokens (e.g. redundant duplicate semicolons ;;) when the following token matches the expected grammar.
  • Panic Mode (Cost 5): Synchronizes to statement boundaries (;, }) only as a last resort to prevent error cascades.

Intelligent Syntax Error Recovery Spotlight

                        
Core academic innovation: continuous parsing through cost-evaluated heuristic error repair

                    


                    

                        

                            
Why Intelligent Recovery?

                            
Standard compilers (e.g. standard GCC, Clang, or naive recursive descent parsers) often abort on the first encountered syntax mistake or trigger uncontrollable cascading error storms. Resilient Compiler uses a local heuristic scoring system to repair defects on-the-fly and complete code generation.

Language Grammar & Compiler Specifications

                        
Formal EBNF definition and execution semantics for the Resilient C-subset dialect

                    


                    

                        

                            
Context-Free Grammar (EBNF)

                            
Program         ::= Statement*
Statement       ::= VarDecl | Assignment | IfStmt | WhileStmt | PrintStmt | Block
VarDecl         ::= Type IDENTIFIER ('=' Expression)? ';'
Type            ::= 'int' | 'float' | 'bool'
Assignment      ::= IDENTIFIER '=' Expression ';'
IfStmt          ::= 'if' '(' Expression ')' Statement ('else' Statement)?
WhileStmt       ::= 'while' '(' Expression ')' Statement
PrintStmt       ::= 'print' Expression ';'
Block           ::= '{' Statement* '}'
Expression      ::= LogicalOr
LogicalOr       ::= LogicalAnd ('||' LogicalAnd)*
LogicalAnd      ::= Equality ('&&' Equality)*
Equality        ::= Relational (('==' | '!=') Relational)*
Relational      ::= Additive (('<' | '<=' | '>' | '>=') Additive)*
Additive        ::= Multiplicative (('+' | '-') Multiplicative)*
Multiplicative  ::= Primary (('*' | '/' | '%') Primary)*
Primary         ::= NUMBER | IDENTIFIER | '(' Expression ')'

                        


                        

                            
Supported Features

                            
    
                                
  • Static Type System: Strong typing for int, float, and bool with declaration validation.

About Resilient Compiler

                        
Intelligent Error Recovery and End-to-End Compiler Design Project

                    


                    

                        

                            
Project Objectives

                            
To demonstrate a resilient, end-to-end compiler that does not break on minor syntax mistakes, but rather intelligently repairs them, constructs a valid AST, performs static semantic checking, generates intermediate three-address code, applies optimizations, and executes the target bytecode on an internal virtual machine.

                        

                        

                            
Core Novelty

                            
The combination of a heuristic 1-token lookahead recovery manager with a full downstream compiler pipeline. Unlike academic compilers that only demonstrate parsing, Resilient Compiler carries repaired syntax through to execution.

                        

                        

                            
Tech Stack & Architecture

                            
Compiler Engine: Modern C++17 without external dependencies.

                            Local Backend: Python 3 standard library HTTP & process runner (server.py).

                            Frontend IDE: Vanilla HTML5, CSS3, ES6 JavaScript with Monaco Editor integration.

                        

                        

                            
Known Limitations & Future Scope

                            
Current version supports local scalar types (int, float, bool). Future iterations could add function declarations, pointers, arrays, and an LLVM IR emitter.
